# support.erase.me
Public help center for Erase.me users: docs, guides and blog-style content, plus a way to raise and follow tickets.
- Content (docs, guides) is Markdown/MDX under `content/`, statically built.
- Raising and viewing tickets needs the user to be signed in; it talks to `services/api` only.
- Ticket handling by staff happens in `apps/admin` (Tickets), never here.
