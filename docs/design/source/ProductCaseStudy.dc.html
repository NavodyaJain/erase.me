Why I cut the admin and support apps from the first build

Nov 16, 2026 · scope decision

Context

The plan had four surfaces: the user app, admin, support and this site. With no users yet, three of them would be built for people who do not exist.

Options

Build everything in parallel, build the user app and API only, or build the user app and handle the rest with a spreadsheet and email.

Decision

Build the user app, the core API and a minimal AI step. Handle admin and support by hand until a specific trigger appears, such as manual handling of requests or support taking hours each week.

What I will check

Whether hand-handling holds up at 15 test users. If it does not, the trigger table says what to build first.

What this cost

The admin and support screens stay as designs only. Less to show, more to learn.
