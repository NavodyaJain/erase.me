# @erase/contracts
Types generated from `services/api/openapi/openapi.json`. Do not edit `src/schema.d.ts` by hand.

- `pnpm --filter @erase/contracts generate` regenerates the types after the API contract changes.
- `pnpm --filter @erase/contracts check` (also run by `pnpm test` and CI) fails if they are out of date.
- Source only: there is no build step. Import from `@erase/contracts`.
