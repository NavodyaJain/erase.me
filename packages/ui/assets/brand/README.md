# Erase.me brand assets
Mark: three rounded rows that shorten and fade (records being erased). Cobalt #2F55F4 tile, white glyph (opacity 100/60/30%).
- `logo-mark.svg`, `favicon.svg`: rounded tile (use anywhere on light or dark).
- `logo-glyph-white.svg` / `logo-glyph-cobalt.svg`: glyph only, transparent.
- `logo-wordmark-light.svg` / `-dark.svg`: mark + "Erase.me" (Inter 700; convert text to outlines before print use).
- `icon-192.png`, `icon-512.png`: PWA "any" icons. `icon-maskable-512.png` (+ `icon-maskable.svg`): PWA maskable, full-bleed, glyph inside the safe zone.
- `apple-touch-icon.png` (180, full-bleed; iOS rounds it), `favicon-16/32.png`, `favicon.ico`.
Manifest: icons 192, 512 (purpose "any") and maskable-512 (purpose "maskable"). theme_color #2F55F4.
