# AGENTS.md

This repository is built with AI coding agents. Start here.

1. Read `docs/product/PRD.md` (what and why) and `docs/architecture/TRD.md` (how).
2. Pick your brief in `docs/agents/` (design, frontend, backend, ai, infra, qa, security-privacy, content) and follow its rules and task order.
3. Shared rules and build order are in `docs/agents/README.md`.
4. Non-negotiables: no request is sent without user approval; no email bodies stored; wording rules in PRD 4.4; no personal data in logs.
5. If anything conflicts or is unclear, stop and write the question in your summary instead of guessing.
